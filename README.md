# Lilt website

Static GitHub Pages site for Lilt. The root contains the home page, with support at `support/` and the privacy policy at `privacy/`. All assets are local and links work under the `/lilt/` project path.

To preview locally, run `python3 -m http.server 8000` from this folder.

In the GitHub repository, choose **Settings → Pages → Deploy from a branch**, then select **main** and **/(root)**. Use the published URLs in App Store Connect.

| Field | URL |
| --- | --- |
| Marketing URL | https://sqhil-a.github.io/lilt/ |
| Support URL | https://sqhil-a.github.io/lilt/support/ |
| Privacy Policy URL | https://sqhil-a.github.io/lilt/privacy/ |

Review the policy when the app’s data practices change. Add a link to the published privacy policy inside the macOS app before submitting for review. The site preview uses original sample art and lyrics.
