Set up Lilt

  1. Open Lilt and find its music note in the macOS menu bar.
  2. Play a song in the Spotify or Apple Music desktop app. Allow Lilt to read playback when macOS asks.
  3. Open the Lilt menu to show the desktop scene, or press ⌃⌥L if you use the default shortcut.

Lilt requires macOS 15 or later.

Lilt can’t see what’s playing

Open Lilt → Settings → Playback and check the music source. If access was denied, enable your player under System Settings → Privacy & Security → Automation → Lilt, then try playing a track again.

Lyrics are missing or out of sync

Some tracks lack timed lyrics. You can import an LRC file for the current song under Settings → Playback → Synchronized Lyrics → Import Local LRC. If the words consistently arrive early or late, adjust Timing offset in the same section. A positive offset makes lyrics appear earlier.

The desktop scene is missing

Check that the scene is enabled in the Lilt menu and that music is playing. Lilt can hide the scene after pausing. To change that behaviour, open Settings → Playback → Desktop Scene. If the scene is on another display, check Settings → Appearance → Desktop → Show on all displays.

Contact support

Email liltwallpapers@gmail.com. Include your macOS version, Lilt version, music player, and what you were doing when the issue appeared. For lyric timing issues, the track title and artist help reproduce it.

For details about playback data and support email, see the privacy policy.
